# Java Exercise Generator

A practice tool for Java programming labs. Instead of copying a fixed sample
program, you pick a real-world scenario — a sari-sari store inventory, a
registration form, a scrapbook Q&A, or a famous person's biography — answer ten
short prompts with your own values, and the app generates the matching Java
program for you to compare against the code you wrote.

The point is repetition with variation: each category has several program
patterns and randomized prompts, so you can drill the same Java concepts
(variables, input, arithmetic, formatting, conditionals) without memorizing one
example.
